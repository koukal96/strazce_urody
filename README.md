# Koukal Website

Exported from Framer by Sourceferry as a static HTML and CSS site (3 pages).

## Open it

Serve this folder with any static server (for example `bunx serve .`) and open the address it prints. Every page is a folder with an index.html, so it works on Netlify, Cloudflare Pages, GitHub Pages, S3 or your own server.

## Pages

- / (Home)
- /dekujeme (Dekujeme)
- /kontakt (Kontakt)

## What didn't carry over

- Effects (shadows, blurs), interactions, animations and hover states aren't readable through Framer's plugin API, so they aren't in the export.
- Text colours come from text styles; text without a text style keeps the inherited colour.
- CMS detail pages are exported once as a layout; the CMS items are in content/ as JSON to bind to it.
- 66 layer-level items in sourceferry-report.csv.
